# Open-source licence compliance

Every component that ships in the installers is listed with its licence, and the licence texts are
shipped with the app and attached to every release. **Not legal advice.**

## What ships

| Part | Licences (typical) | Notices |
| --- | --- | --- |
| npm runtime dependencies and the libraries bundled into the UI (React, TipTap, DOMPurify, Lucide …) | MIT, ISC, BSD, Apache-2.0, MPL-2.0 (DOMPurify dual), 0BSD | `THIRD-PARTY-NOTICES.txt` (generated by `npm run notices`, checked in CI) |
| Electron (Chromium, Node.js, V8, FFmpeg) | MIT + Chromium's own notices (BSD, LGPL-2.1 for FFmpeg build, …) | `LICENSE` and `LICENSES.chromium.html` that electron-builder copies into every installer |
| Bundled CPython (python-build-standalone) | PSF-2.0 (+ OpenSSL Apache-2.0, SQLite public domain, libffi MIT, …) | `resources/ai-runtime/python/LICENSE*` |
| Python packages of the AI sidecar (Orkexa, Tabrion, pydantic, httpx, openai, anthropic …) | MIT, Apache-2.0, BSD | `resources/ai-runtime/THIRD-PARTY-PYTHON.txt` (written by `scripts/build-ai-runtime.mjs`, licence policy checked there) |
| Ollama (bundled binary incl. llama.cpp/ggml) | MIT (+ vendor GPU libraries under their licences) | `resources/ollama/LICENSE-ollama.txt` |
| Local models (downloaded on demand, **not** shipped in the installer) | all models of the fixed catalog are Apache-2.0 (Qwen, Gemma 4, Ministral, Mistral Small, Qwen3-Embedding) or MIT (BGE-M3), read from each manifest's licence layer | licence shown in the model list in Settings → AI & agents; [docs/ai/MODELS.md](../ai/MODELS.md) |
| Icons | Lucide (ISC); the UI uses the system fonts, no font files are shipped | in THIRD-PARTY-NOTICES |
| Levuvo Mail itself | proprietary, "All rights reserved" ([LICENSE](../../LICENSE)) | – |

## Policy

- **Allowed without review:** MIT, ISC, BSD-2/3-Clause, Apache-2.0, 0BSD, Unlicense, CC0-1.0,
  Python-2.0/PSF-2.0, Zlib, BlueOak-1.0.0, CC-BY-4.0 (data only), MPL-2.0 (unmodified files, weak copyleft).
- **Review needed:** LGPL (dynamic linking only, allow replacement), EPL, CDDL, any custom licence,
  model licences with use restrictions.
- **Not allowed in the product:** GPL, AGPL, SSPL, BUSL and other licences that would require
  publishing Levuvo Mail's source or restrict commercial use, unless used as a separate program with
  a lawyer's approval.
- Enforced by `npm run check:licenses` (npm) and the AI runtime build (Python) in CI; exceptions are
  listed with a reason in `scripts/license-policy.json`.

## Duties when distributing

1. Ship the licence texts and copyright notices (MIT/BSD/ISC/Apache §4) – done via the notice files.
2. Apache-2.0 `NOTICE` files are reproduced – the notice generators include them.
3. MPL-2.0: point to the source of the covered files (unmodified, from npm).
4. LGPL parts of Chromium/FFmpeg are dynamically linked by Electron; Electron's own compliance applies.
5. Model licences: only permissive licences are admitted to the catalog (`apps/server/src/ai-model-catalog.mjs`); `npm run check:models` checks the pins, a new model needs a licence review.
6. Show licences in the app: Settings → About → "Open-source licences" opens the bundled notice files.
7. Attach `THIRD-PARTY-NOTICES.txt` and the SBOM to every release (release workflow).
