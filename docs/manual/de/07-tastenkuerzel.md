# Tastenkürzel

In der E-Mail-Ansicht zeigt `?` diese Übersicht an. Auf dem Mac nimmst du `⌘` statt `Strg` und `⌥` (Wahltaste) statt `Alt`.

:::columns

## Überall

| Tasten | Aktion |
|---|---|
| `Strg` + `K` | Befehlspalette öffnen |
| `Strg` + `J` | Assistent öffnen |
| `Alt` + `1` | E-Mail |
| `Alt` + `2` | Kalender |
| `Alt` + `3` | Kontakte |
| `Alt` + `4` | Räume |
| `Alt` + `5` | Aufgaben |
| `Alt` + `,` | Einstellungen |
| `Esc` | Schließen oder Auswahl aufheben |

:::next

## In der Mail

| Tasten | Aktion |
|---|---|
| `J` / `K` | Nächste oder vorherige Nachricht |
| `N` | Neue Nachricht |
| `R` | Antworten |
| `A` | Allen antworten |
| `F` | Weiterleiten |
| `U` | Gelesen oder ungelesen |
| `S` | Markieren (Stern) |
| `E` | Archivieren |
| `B` | Zurückstellen |
| `!` | Spam oder kein Spam |
| `Entf` | In den Papierkorb |
| `P` | Drucken oder als PDF speichern |
| `/` | Suchen |
| `Strg` + `Enter` | Senden (im Editor) |
| `?` | Übersicht der Tastenkürzel |

:::end
