# Begriffe kurz erklärt

| Begriff | Bedeutung |
|---|---|
| App-Passwort | Ein eigenes Passwort nur für Levuvo Mail, erzeugt im Konto deines Anbieters. |
| CalDAV, CardDAV | Standards, mit denen Kalender und Kontakte abgeglichen werden, etwa mit Nextcloud. |
| Cloud-Modell | Ein KI-Modell, das auf den Servern eines Anbieters läuft. Die Inhalte werden dafür dorthin übertragen. |
| Ende-zu-Ende-verschlüsselt | Nur Absender und Empfänger können den Inhalt lesen. |
| IMAP, SMTP | IMAP holt deine Mails vom Server, SMTP verschickt sie. |
| KI-generiert | Vom Assistenten erstellter Text. Er ist immer gekennzeichnet. |
| Lokales Modell | Ein KI-Modell auf deinem Computer. Nichts verlässt das Gerät. |
| MCP | Eine Schnittstelle, über die externe KI-Programme mit festgelegten Rechten auf Levuvo Mail zugreifen. |
| Prüfsumme | Ein digitaler Fingerabdruck einer Datei. Stimmt er, ist die Datei unverändert. |
| Ollama | Das Programm, das lokale KI-Modelle ausführt. Levuvo Mail bringt ein eigenes mit. |
| OpenPGP, S/MIME | Zwei Standards zum Verschlüsseln und Unterschreiben von Mails. |
| Phishing | Betrugsmails, die dich zu einer Zahlung oder zur Eingabe von Passwörtern bringen wollen. |
| RAM, Arbeitsspeicher | Der schnelle Speicher deines Computers, in GB. Lokale KI braucht viel davon. |
| Schlüsselbund | Der sichere Passwortspeicher deines Computers. Unter Windows heißt er Anmeldeinformationsverwaltung. |
| Sieve | Ein Standard für Filterregeln, die direkt auf dem Mailserver laufen. |
| Suchindex | Ein verschlüsseltes Verzeichnis deiner Mails auf dem Computer, damit die Suche schnell und auch offline klappt. |
| Suchmodell | Ein kleines KI-Modell, mit dem die Suche nach Bedeutung statt nur nach Wörtern sucht. |
