# Keyboard shortcuts

Press `?` to see this overview in Levuvo Mail at any time. On a Mac, use `⌘` instead of `Ctrl`.

:::columns

## Everywhere

| Keys | Action |
|---|---|
| `Ctrl` + `K` | Open command search |
| `Ctrl` + `J` | Open the assistant |
| `Alt` + `1` | Email |
| `Alt` + `2` | Calendar |
| `Alt` + `3` | Contacts |
| `Alt` + `4` | Spaces |
| `Alt` + `5` | Tasks |
| `Alt` + `,` | Settings |
| `Esc` | Close or clear selection |
| `?` | Shortcut overview |

:::next

## In email

| Keys | Action |
|---|---|
| `J` / `K` | Next or previous message |
| `N` | New message |
| `R` | Reply |
| `A` | Reply all |
| `F` | Forward |
| `U` | Read or unread |
| `S` | Star |
| `E` | Archive |
| `B` | Snooze |
| `!` | Spam or not spam |
| `Delete` | Move to bin |
| `P` | Print or save as PDF |
| `/` | Search |
| `Ctrl` + `Enter` | Send (in the editor) |

:::end
