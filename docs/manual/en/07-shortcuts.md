# Keyboard shortcuts

In the email view, `?` shows this overview. On a Mac, use `⌘` instead of `Ctrl` and `⌥` (Option) instead of `Alt`.

:::columns

## Everywhere

| Keys | Action |
|---|---|
| `Ctrl` + `K` | Open command palette |
| `Ctrl` + `J` | Open the assistant |
| `Alt` + `1` | Email |
| `Alt` + `2` | Calendar |
| `Alt` + `3` | Contacts |
| `Alt` + `4` | Spaces |
| `Alt` + `5` | Tasks |
| `Alt` + `,` | Settings |
| `Esc` | Close or clear selection |

:::next

## In email

| Keys | Action |
|---|---|
| `J` / `K` | Next or previous message |
| `N` | New message |
| `R` | Reply |
| `A` | Reply all |
| `F` | Forward |
| `U` | Read or unread |
| `S` | Star |
| `E` | Archive |
| `B` | Snooze |
| `!` | Spam or not spam |
| `Del` | Move to trash |
| `P` | Print or save as PDF |
| `/` | Search |
| `Ctrl` + `Enter` | Send (in the editor) |
| `?` | Shortcut overview |

:::end
