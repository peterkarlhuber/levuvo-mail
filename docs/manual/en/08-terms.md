# Terms explained

| Term | Meaning |
|---|---|
| AI-generated | Text the assistant created. Levuvo Mail always labels it. |
| App password | A separate password just for one program such as Levuvo Mail. You create it in your provider's account, so your main password stays secret. |
| CalDAV, CardDAV | Standards that keep calendars and contacts in sync between devices, for example with Nextcloud or iCloud. |
| Cloud model | An AI model that runs on a provider's servers. The content is sent there for it. |
| End-to-end encrypted | Only sender and recipient can read the content, nobody in between. |
| IMAP, SMTP | IMAP fetches your email from the server, SMTP sends it. Levuvo Mail sets up both automatically for well-known providers. |
| Keychain | Your computer's secure password store. On Windows it is called Credential Manager. |
| Local model | An AI model that runs on your computer. Nothing leaves the device. |
| MCP | An interface through which external AI programs access Levuvo Mail with fixed rights. |
| Ollama | The program that runs local AI models. Levuvo Mail brings its own. |
| OpenPGP, S/MIME | Two standards for encrypting and signing email. |
| Phishing | Fraudulent emails that try to get you to pay or to enter passwords. |
| Search index | An encrypted directory of your emails on your computer, so search is fast and works offline. |
| Search model | A small AI model that lets search look for meaning instead of only words. |
| Sieve | A standard for filter rules that run directly on the mail server. |
